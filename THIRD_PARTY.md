# Third-party policy

The core package currently vendors no third-party source, model weights, or datasets.
Runtime Python dependencies are resolved from their upstream packages and retain
their licenses. Optional projects listed in `docs/PRIOR_ART.md` are architectural
references or user-installed adapters, not bundled components.

Before adding an asset, record separately its source, revision, copyright, code
license, model-weight license, dataset terms, documentation/content license,
redistribution permission, and intended commercial boundary.
